# Oluwaseun Ayoola — GitHub Pages portfolio

1. Create a public repository named `oluwaseunayoola42.github.io`.
2. Upload `index.html` to the repository root and commit.
3. Go to Settings → Pages → Deploy from a branch; select `main` and `/(root)`, then Save.
4. Once deployed, visit https://oluwaseunayoola42.github.io.

The project cards currently link to your GitHub profile because exact repository URLs were not available to verify. To make each card open its specific project, replace the `href` on that card with the repository's exact URL.
